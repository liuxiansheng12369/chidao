# 状态栏歌词控制面板 ·「词岛卡片」

版本：**2.2.47**（versionCode 2855，2026-11-26）
移植来源：副本 `D:\Android\chidao-panel`（2.2.46 验证通过后搬回主项目）

## 用法

1. 设置 → 状态栏歌词 → 交互 → **控制面板样式** → 选「词岛卡片」
   - 另两项：经典卡片、下拉媒体卡
2. 单击动作设为「控制面板」（手势那一栏已有）
3. 点系统状态栏上滚动的那段歌词 → 弹出卡片

卡片内容：歌曲区（封面 / 歌名 / 歌手 / 进度条 / 时间 / 上一首·播放暂停·下一首）+ 快速设置（显示内容三档、歌词字号 −/＋、彩虹歌词、避让超级岛）。

显示内容「不显示」= 状态栏不再有歌词，面板入口也随之消失，需进 App 首页「状态栏歌词」入口改回来。

面板在 SystemUI 进程里，只能读 prefs、不能写 App 私有目录，所以按钮发定向广播 `com.liuxiansheng.lyricon.v3.STATUS_BAR_QUICK_SET` 给 App，由 `StatusBarPrefs` 正规写入（remote + 本地 + `BridgeSender` 通知 SystemUI），与在设置页改完全等效。

## 三处顺带修掉的旧问题

- **改设置要重启系统界面才生效**：`remount()` 取 `rootRef` 拿不到东西时直接跳过重建（SystemUI 重启 / 窗口重建后根容器已换代）。现在先用旧 wrapper 的 `parent` 兜底当挂载点。
- **面板下半截看得见点不动**：`PopupWindow` 用 `WRAP_CONTENT` 时 SystemUI 按上半截算窗口高度，下半部分画在窗口外，触摸穿透到桌面（点「彩虹」会打开相册）。现在 show 前显式 measure，把实测高度写死。
- **冷启动拉起 App 时设置不生效**：接收器是被广播拉起来的进程，`BridgeSender` 只在两个 Activity 里初始化过，`notifyPrefChanged` 因无 context 静默丢弃。接收器 `onReceive` 开头补一次 `BridgeSender.initialize`。

## 注意

- SystemUI 侧代码变更后必须重启一次系统界面（`killall com.android.systemui`）才加载新模块
- 设备上「控制面板样式」本地值可能被 remote 回填成 1（媒体卡），切换无效时回设置页重选一次「词岛卡片」
